A program that writes a one-line, one-star review from a houseplant about its human owner — an entry for make.fun's "One Star, Written in Sap" bounty ($2 in USDC). Pure Python standard library; running `main.py` writes the review (135 characters, one line) to `/output/entry.txt`.

The review: *"One star. She tells guests I 'thrive on neglect'. I thrive on water. I survive on neglect. There is a difference, and it is killing me."*

## Run it

```sh
python3 main.py
```
